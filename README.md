# 魔方社

> 一份由在校学生自愿组成、独立运转的魔方交流组织的章程与配套规范性文件。

---

## 这是什么

一份由中学生撰写的社团章程——但读起来像一部微型宪法。

组织定位为**由在校学生自愿组成、独立运转的兴趣团体**：不谋求获得学校官方认定，亦不以成为学校官方学生组织为目标；同时愿在平等基础上与学校保持合作、共同发展（见第四十八条）。

若组织所依托的学校未来事实上被严重分裂或因招生不足而关闭，本组织将脱离该校转为面向社会开放的魔方社群，并依法申请社会团体登记。

## 前言

本组织由在校学生自愿组成，以魔方交流与推广为主要目的。

我们设立这份章程，是为组织立下一套根本规范：明确权力从何而来、归于何处，明确成员享有哪些不可剥夺的基本权利、承担哪些基本义务，并把一切权力都纳入程序的约束之中。

本组织自主设立、自主运行、自主存续。

本组织以成员为本，以在校成员为根基，以传承为愿景。

## 架构

```
全体成员会议（最高权力机构，由全体成员组成）
  ├── 常任委员会（闭会期间的常设机构，对全会负责）
  ├── 组织代表（常设权力机构，仅由在校成员担任）
  ├── 监察委员会（程序监督机构：只盯权力运行的程序合法性）
  ├── 纪律调查委员会（调查机构：对个人的违规享有调查权，能查不能判）
  ├── 审裁委员会（审判机构：对个人违规与机构争议享有审判权与处罚权，不能搜查）
  ├── 资产管理委员会（特殊功能性机构，受章程级保护，独立对全会负责）
  ├── 档案管理委员会（负责史料与档案的收集、整理、保管与公开）
  ├── 运营委员会（功能性机构，负责数字平台建设与运营）
  ├── 行政部门（常设行政机构，设活动与教学两条工作线）
  ├── 工作小组（为工作方案或应急事件临时组建，任务完成即散）
  └── 联络员制度（以班级为单位设立，为无法线上参与者传递信息与代为投票）
```

## 核心特征

- **权力分散与制衡**：管账的不花钱（资产管理委员会），花钱的不记账（常任委员会），查账的不管钱（监察委员会）；常任委员会、资产管理委员会、监察委员会、纪律调查委员会、审裁委员会与组织代表**六方成员互不兼任**
- **调查权与审判权分离**：**查的人不判，判的人不查**——纪律调查委员会享有调查权（搜查、取证、询问），能查不能判；审裁委员会享有审判权与处罚权，能判不能查；监察委员会三者的对象均非个人，而是**机构行使权力的程序**
- **解释权分层**：全体成员会议（最高，可解释章程与规则）→ 常任委员会（次高，可解释章程与规则）→ 审裁委员会（可解释规则、办法、规范，**不得解释章程**）；下位解释与上位解释抵触时以上位为准，上级有权推翻下级
- **在校成员主导**：全体成员会议中在校成员占比不得少于 52%；组织代表仅得由在校成员担任；各机构席位与候选名单均设有在校成员保障比例（见第十二条之一）
- **系数票权**：表决按系数折算票权——在校成员 1.0、校友成员 0.7、校外成员 0.5；选举投票权为在校成员专属
- **信息防垄断**：联络员制为不能上网的成员传话收票；成员以内部编号与昵称标识，组织对真实身份信息完全不作收集
- **自我纠错**：三档表决制（普通／大型／重大）、代号记名表决、利益回避、监察委员会程序异议、纪律调查委员会独立调查、审裁委员会终局裁决、成员申诉权

## 规范性文件四层体系

章程第五条之一确立规范性文件的四层结构，依效力由高至低为：

| 层级 | 名称 | 制定/修改权 | 表决门槛 | 管辖 |
|---|---|---|---|---|
| 一 | **章程** | 全体成员会议 | 根本性条款→重大事项；其余→大型事项 | — |
| 二 | **规则** | 全体成员会议 | 普通事项 | — |
| 三 | **办法** | 相应机构 | 由该机构规定 | 制定机构 |
| 四 | **规范** | 相应机构 | 由该机构规定 | 该机构内所有成员 |

- **效力**：下位不得抵触上位，抵触时以上位为准。
- **监督**：全体成员会议及其常任委员会对办法与规范享有监督权。
- **分置原则**：各机构的**根本性质、地位与权力结构**由章程规定；其**职权范围、权限边界与具体运行程序**由相应规则规定。
- **根本性事项专属章程**：涉及组织之性质、权力之来源与归属、以及成员之间基本权利义务的事项，仅得由章程规定，规则、办法或规范均不得创设、变更或剥夺。

> 机构规范的分置是本体系的直接体现：《机构运行》规则载有各机构的席位名额、职权清单与议事程序；章程则只保留各机构的设立依据、根本性质、地位与权力来源。

## 解释权层级

章程第六条之二将规范性文件的解释权按主体分层配置：

| 解释主体 | 可解释层级 |
|---|---|
| **全体成员会议** | 章程、规则（**最高解释权**） |
| **常任委员会** | 章程、规则（**次高解释权**） |
| **审裁委员会** | 规则、办法、规范（**不得解释章程**） |

- 下位解释与上位解释相抵触时，以上位解释为准；**上级主体有权推翻下级主体所作之解释**。
- 全体成员会议之解释为**最终解释**。
- 审裁委员会审理案件时遇章程条文含义不清，应**移送常任委员会解释**，不得自行作出章程解释。
- 任何对章程条款的官方解释，均须经解释主体以过半数表决通过后方可生效。

## 双版本说明

规范性文件同时存在两种文本，二者互补、指向同一套规则：

- **通俗版（简单版）**：以例子为核心、语言通俗，是**日常陈述与执行的默认版本**；多数情形下直接采用通俗版。
- **严谨版**：表述精确、面向权责界定，用于**特殊情形**（正式决议、对外正式文件、争议裁决、需精确界定权责的场合）。
- **替代执行**：当严谨版缺失或不适用时，通俗版可替代严谨版执行，即通俗版具有独立的可执行效力。
- **对照使用**：两版对应条文编号一致、哈希一致，可逐条对照。查阅时建议以**通俗版**理解含义、以**严谨版**确定权责边界。

数据库 `charter.db` 的 `articles` 表通过 `version` 标签（`严谨` / `通俗`）区分两版；同一文件的同一条文在两版中编号一致、哈希一致。

## 条文唯一编号（内容哈希）

每条条文拥有一个基于其正文内容计算的唯一编号（sha256 前 8 位十六进制），生成后即**永久冻结**：条文重新编号不变、条文内容被修订也不变。它是条文的身份标识，不是内容校验和——这样任何引用都不会因修章而失效：

- **标题格式**：`**第X条#hash**`（如 `**第二十五条#0d51bd10**`）
- **引用格式**：以 `#hash` 指代被引用条文
- **双版本哈希统一**：同一规则在严谨版与通俗版中的哈希一致（以严谨版为基准计算，通俗版标题对齐）
- **插入式编号**：新增条文以「第五条之一」形式插入，不重排既有条号，避免引用失效
- **修订不改编号**：条文正文被修改时沿用原编号；只有**新增**条文才生成新编号
- **数据库落库**：`articles` 表以 `hash` 列存储该值，便于精确引用与跨版本定位

> 引用示例：章程第七条中「依#e970f445第1项按0.7系数折算」，即引用同章第十二条之一所定之表决计票系数。

> —— 第二条
