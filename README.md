# 魔方社

> 一个初中魔方社团的章程（临时版），73条，14章，分布着大量权力约束机制。

---

## 这是什么

一份由初中生撰写的社团章程——但读起来像一部微型宪法。

组织定位为**由在校学生自愿组成、独立运转的兴趣团体**：不谋求获得学校官方认定，亦不以成为学校官方学生组织为目标；同时愿在现有基础上与学校保持合作、共同发展（见第五十八条）。若组织所依托的学校未来事实上被严重分裂或因招生不足而关闭，本组织将脱离该校转为面向社会开放的魔方社群，并依法申请社会团体登记。

## 架构

```
全体成员会议（最高权力）
  ├── 常任委员会（日常执行）
  ├── 组织代表（临危决断）
  ├── 监察委员会（独立合规审查）
  ├── 经费管理委员会（独立管账，直接对全会负责）
  ├── 历史管理委员会（记录传承）
  ├── 安全管理委员会（活动安全）
  ├── 运营小组（线上网站与平台维护）
  └── 联络员制度（为无法上网者传递信息与代为投票）
```

## 核心特征

- **权力分散：** 管账的不花钱（经费委），花钱的不记账（常任委），查账的不管钱（监察委）
- **自我纠错：** 大量约束分布在73条中——从24小时会议通知到被否提案14日冷却，从利益回避到代号匿名投票
- **分阶段演进：** 初创期由临时发展工作组集体代行决策权，创始人任召集人；满15人召开第一次全体成员会议；会后14日内完成所有机构的选举，工作组随即解散
- **信息防垄断：** 联络员制为不能上网的成员传话收票；档案可公开部分主动公开

## 规范性文件四层体系

章程第五条之一确立规范性文件的四层结构，依效力由高至低为：

| 层级 | 名称 | 制定/修改权 | 表决门槛 | 管辖 |
|---|---|---|---|---|
| 一 | **章程** | 全体成员会议 | 根本性条款→重大事项；其余→大型事项 | — |
| 二 | **规则** | 全体成员会议 | 普通事项 | — |
| 三 | **办法** | 相应机构 | 由该机构规定 | 制定机构 |
| 四 | **手册** | 相应机构 | 由该机构规定 | 该机构内所有成员 |

- **效力**：下位不得抵触上位，抵触时以上位为准。
- **监督**：全体成员会议及其常任委员会对办法与手册享有监督权。
- **分置原则**：各机构的**根本性质、地位与权力结构**由章程规定；其**职权范围、权限边界与具体运行程序**由相应规则规定。
- **根本性事项专属章程**：涉及组织之性质、权力之来源与归属、以及成员之间基本权利义务的事项，仅得由章程规定。

## 双版本说明

每份规范性文件同时存在两种文本，二者互补、指向同一套规则：

- **通俗版（简单版）**：以例子为核心、语言通俗，是**日常陈述与执行的默认版本**；多数情形下直接采用通俗版。
- **严谨版**：以政治语言为核心、表述精确，用于**特殊情形**（正式决议、对外正式文件、争议裁决、需精确界定权责的场合）。
- **替代执行**：当严谨版缺失或不适用时，通俗版可替代严谨版执行，即通俗版具有独立的可执行效力。
- **机构规范分置**：全体会工作、常任委会运作、监察委员会调查、经费管理、运营委员会 5 份委员会工作规范的**根本性质与地位**已并入主章程相应章节（第四至九章），其**职权与运行程序**由相应规则承接；特殊身份、历史管理委员会、运营委员会、事项分类、处罚 5 份规则作为独立文件与本章程配套施行（运营委员会规则明确其数据库运营权与代码编写权；事项分类规则明确普通/大型/重大事项的三档表决划分；处罚规则明确违规行为、处罚种类与程序）。

数据库 `charter.db` 的 `articles` 表通过 `version` 标签（`严谨` / `通俗`）区分两版，同一文件的同一条文在两版中编号一致。

## 条文唯一编号（内容哈希）

每条条文拥有一个基于其正文内容计算的唯一编号（sha256 前 8 位十六进制），生成后即**永久冻结**：条文重新编号不变、条文内容被修订也不变。它是条文的身份标识，不是内容校验和——这样任何引用都不会因修章而失效：

- **标题格式**：`**第X条#hash**`（如 `**第三十五条#d9b0f724**`）
- **引用格式**：以 `#hash` 指代被引用条文；原「章程第N条 / 第N条」表述已全部改写为此形式
- **双版本哈希统一**：同一规则在严谨版与通俗版中的哈希一致（以严谨版为基准计算，通俗版标题对齐）
- **插入式编号**：新增条文以「第五条之一」形式插入，不重排既有条号，避免引用失效
- **数据库落库**：`articles` 表新增 `hash` 列存储该值，便于精确引用与跨版本定位
- **修订不改编号**：条文正文被修改时沿用原编号；只有**新增**条文才生成新编号

> 例：特殊身份规则中「由常任委员会依据#9a265b9b授权制定」即引用主章程第十四条。

## 仓库所有权

本仓库当前由创建者持有。待本仓库所含章程所建立之组织正式成立并实际运转后，本仓库之所有权将由该组织中的一部分（某一组成机构）接管。

> —— 第二条

> 若组织所依托的学校事实上被严重分裂或因招生不足而关闭，本组织将脱离该校转为面向社会开放的魔方社群，在具备足够人数且拥有固定活动形式后，依法申请社会团体登记。此为该组织之传承愿景（原章程条款已移出正文，保留于此）。
